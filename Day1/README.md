# Day 1 — First Look at the Data

## What I practiced
- Importing `pandas`
- Loading an Excel file into a DataFrame with `pd.read_excel()`
- Previewing data with `.head(10)` and `.tail(8)`
- Checking the shape of the dataset with `.shape`
- Getting column info and data types with `.info()` and `.dtypes`
- Getting summary statistics with `.describe()`
- Listing column names with `.columns`
